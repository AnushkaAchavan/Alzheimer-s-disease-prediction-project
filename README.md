# NeuroClear Flask Handoff

This package contains the Flask UI integration for the Alzheimer MRI project with full support for:

- 3-class prediction: `CN`, `MCI`, `AD`
- `Grad-CAM`
- `LIME`
- `SHAP`

It is meant to be handed to the teammate who already has the trained model artifacts and XAI assets.

## Included In This Package

- `app.py`
- `requirements.txt`
- `model/ensemble_model.py`
- `model/__init__.py`
- `explainability/grad_cam.py`
- `explainability/lime_explain.py`
- `explainability/shap_explain.py`
- `explainability/__init__.py`
- `templates/index.html`
- `templates/auth.html`
- `static/neuroclear-logo.png`
- empty `models/`, `static/uploads/`, and `static/xai/` folders

## Files Your Teammate Must Add

### 1. Trained model weights

Place the trained PyTorch weights at:

- `models/best_model_phase2.pth`

Or set:

- `ALZHEIMER_MODEL_WEIGHTS`

PowerShell example:

```powershell
$env:ALZHEIMER_MODEL_WEIGHTS="C:\full\path\to\best_model_phase2.pth"
```

### 2. SHAP background tensor

If she wants `SHAP` to run, place the background tensor at:

- `models/shap_background.pt`

Or set:

- `ALZHEIMER_SHAP_BACKGROUND`

PowerShell example:

```powershell
$env:ALZHEIMER_SHAP_BACKGROUND="C:\full\path\to\shap_background.pt"
```

Without `shap_background.pt`, `Grad-CAM` and `LIME` will still work, but `SHAP` will return an error until the background file is provided.

## Runtime Behavior

The UI sends:

- `mri_file`
- `age`
- `gender`
- `xai_method`

Supported XAI methods:

- `Grad-CAM`
- `LIME`
- `SHAP`

Supported upload formats:

- `.png`
- `.jpg`
- `.jpeg`
- `.nii`
- `.dcm`

## How To Run

1. Open a terminal in this folder.
2. Create and activate a virtual environment.
3. Install dependencies.
4. Add `best_model_phase2.pth`.
5. Add `shap_background.pt` if SHAP is needed.
6. Start the Flask app.

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Then open:

- `http://127.0.0.1:5000`

## Default Login

- username: `admin`
- password: `admin123`

Registered users are stored in memory for the current app session only.

## Output Contract

The backend returns:

- predicted class
- confidence
- probabilities for `cn`, `mci`, `ad`
- XAI method used
- XAI explanation text
- XAI visualization image URL

## Notes About The XAI Integration

- `Grad-CAM` uses the provided `explainability/grad_cam.py`.
- `LIME` uses the provided `explainability/lime_explain.py`.
- `SHAP` uses the provided `explainability/shap_explain.py`.
- SHAP is loaded on CPU and is usually the slowest option.
- The result page displays the visualization generated by the selected XAI method.

## If Something Fails

- If the app says model weights were not found, check `models/best_model_phase2.pth`.
- If SHAP fails because the background file is missing, add `models/shap_background.pt`.
- If the state dict does not load, the `.pth` file may belong to a different architecture.
- If imports fail, reinstall dependencies inside the virtual environment.
